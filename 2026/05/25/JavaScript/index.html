JavaScript

浏览器是js最原始的运行环境，Node.js提供了运行环境，使得js可以脱离浏览器运行，并进行文件读写等。但是node.js里不可以操作浏览器专属的功能，例如alert弹出对话框

新建一个js文件并写入语句，在对应的目录里启动命令行，输入node [文件名]，即可使用node.js运行该文件

ES6：JavaScript的正式名称为ECMAScript，ES6指其在2015年发布的第六大版本，引入的新语法特性已成为标准写法

输出

  • js打印时多个内容使用逗号分隔，也可以在打印的时候${}引入变量（注意这个时候就要使用``来引用内容
  • console.log默认自动换行，可以使用process.stdout.wirite不换行，但是输入数字的话需要先转为字符串

输入

使用readline从标准输入中逐行读入数据

变量

let：声明可以修改的变量，且声明时可以不用赋值

const：声明常量，赋值后不可以修改

var：js早期声明变量的方式，功能和let类似，但是有一些缺陷，不再使用

变量类型：number、string、boolean、null、undefined

  • 整数和小数都是number不区分
  • string使用单引号、双引号、反引号均可，其中反引号支持插入变量
  • boolean只有true和false两个值
  • typeof null返回object

类型转换函数：

  • parseInt转整数数字、parseFloat转小数（安全型，可以转换不是纯包含数字的字符串）
  • String转字符串
  • Number转数字，遇到非数字字符则返回错误
  • 字符串拼接使用+号，而其他的运算字符则会把字符串转为数字运算，所以算加法要保证两个操作数都必须是数字

运算符：

  • /是除法，带小数。整数除法使用Math.floor取整
  • **是幂运算
  • ===严格相等，!==严格不等，永远只使用这两个运算符进行比较
  • &&与||分别为逻辑与和逻辑或，!逻辑非，取反
  • 位运算和C/C++一致

语句

  • if/else if/else的语法与C/C++一致、while、continue、break、switch用法一致（switch注意每个情况后break）

  • for的一个新用法：使用of遍历元素

异常处理

使用throw抛出错误，使用try-catch-finally处理错误

常见的错误类型：TypeError、RangeError、SyntaxError等

前端常见需要进行错误处理

js中大量常用功能全局可用，不需要导入，但还是在node.js环境中，有些模块还是需要require加载

  • 使用module.exports导出内容，此时被引入的模块在源文件中需要挂载

ES6模块：在之前的项目里有看到过

  • 带大括号表示按照名字导入，源文件里面被导入的这个模块命名必须一致
  • 不带大括号表示导入默认导出，也就是在源文件里面是export default xxxx，此时导入的时候名字不一定和原来的保持一致

函数

js使用function关键词定义函数

  • js中函数参数不需要写类型，只写参数名
  • 如果函数没有return语句或者没有return值，那么返回值就是undefined

箭头函数：（非常之重要

  • 使用=>定义函数
  • 箭头函数和普通函数的区别是：箭头函数没有自己的this，使用的是定义时外层作用域的this。而普通函数的this取决于他是怎么被调用的，因此对象方法一般不写成箭头函数（因为对象方法经常需要this，但是箭头函数的this不是想要的this）；箭头函数也不会有函数提升，也就是不能在定义函数之前不能被使用，和普通函数不同
  • ...args剩余参数

函数可以作为元素值、可以作为参数

闭包

闭包需要满足的条件：

  • 函数里面定义了另一个函数
  • 内函数使用了外函数定义的变量
  • 内函数被返回，或者在外部被继续使用

此时内部函数使用的那个变量就会被留下来，不会随着外部函数的结束而消失，也就函数在外部继续执行时，还能访问它定义时的外层变量。

原型链

js在设计之初并没有class的概念，class是ES6引入的语法糖，实际使用的是prototype chain原型链来实现类的机制

原有写法使用函数构建对象，方法挂载在prototype上。虽然现在引入了class的写法，但底层的机制没有改变

prototype：每个函数都具有的一个属性，这个属性是一个对象，当创建实例时，实例会自动获得一个隐藏链接指向构造函数的prototype。

因此，当访问实例上不存在的属性或者方法时，就会沿着此链接在prototype寻找

根据实现原理，construct构造函数里面的属于是实例自己有的，而定义的方法这些就是挂载在prototype上的，是所有实例共有的，但是因为这些方法处理的又都是实例自己拥有的变量，所以不会冲突

也就是说，实例自己的属性存在实例上自己私有，方法存在prototype上大家共享

如果prototype有没有，js会继续向上寻找，因为prototype作为对象也有自己的原型，这条路径就成为原型链

js中所有对象的原型链最终都指向Object.prototype，然后到null结束，所以任何对象都可以调用到挂载在Object.prototype上的函数

异步编程

事件循环

js在设计之初即为单线程，通过事件循环和异步回调来实现并发

首先需要理解并发的概念：

  • 同步：指事情一件接一件的做，在代码里表现为上一行代码没执行完下一步代码不会被执行
  • 异步：单线程，在等待的间隙切换任务，使得多件事情可以同时推进
  • 并行：并行是真正意义上的同时，比如三个人同时干三件事情，在电脑里就是需要多个CPU核心，每个核心执行不同的代码
  • 并发：比较宽泛的概念，只要多件事情在同一个时间段内都在推进就叫做并发。所以并发是一个目标或者想要达成的效果，而异步和并行是实现并发的两个手段

JS是单线程+事件循环，通过异步来实现并发，但永远不会并行，因为同一时刻只会有一段js代码在执行，不会出现两段js代码同时在跑的情况

事件循环Event Loop的含义：

  • 调用栈：当前正在执行的代码，函数调用时压栈执行完后出栈，每次只从栈顶取一个任务执行
  • 任务队列：等候区，异步操作（比如 setTimeout、网络请求）完成后，它的回调函数不会立刻执行，而是被放进任务队列排队。只有当调用栈清空了（当前代码执行完了），事件循环才会从队列里取出下一个任务放进调用栈执行。

可以看一个setTimeout的代码来理解这个地方：

在真正执行的时候，先输出的是1和3，最后输出的是2，因为2里面的异步操作使得这个回调函数被放进了任务队列，直到3执行完后调用栈为空才从任务队列里面取出2来执行。所以setTimeout(0)不是0秒后执行，而是当前代码跑完后尽快执行

而setTimeout的时间参数的真实含义是：回调最早只能在xms后执行，或者说，最早只能在xms后将这个回调放入任务队列，等待调用栈为空后执行。

由此可以总结出时间循环的核心规则：同步代码优先，异步回调排队

回调函数

回调函数是异步编程方式之一

其含义是：将一个函数作为参数传入，待异步操作完成后，由系统调用该函数，并传回结果

Promise

ES6引入的异步编程方案。一个promise对象有三种状态：

  • pending：进行中
  • fulfilled：已完成，有结果
  • rejected：操作失败，有错误

一个promise对象只能从pending变为后两种状态，一旦改变就不会再变

可以理解为：Promise是一个未来才会有结果的对象，比如请求数据、读文件、定时器等操作不是马上就会完成的

再来理解一下resolve和.then：

  • resolve实在Promise里面交付结果的，下面那个例子里面resolve的作用就是告诉Promise异步任务成功了，结果是”数据-42”。也就是说reslove里面给出的成功的结果
  • 而.then就是在Promise外面接收结果，意思是在Promise成功之后，要拿到成功的结果，并做一些事情

Promise还支持链式调用，这个时候.then()返回的还是一个Promise，所以可以继续.then()

如果是处理多个异步操作，使用Promise.all，等待所有的Promise完成

这里的例子需要注意一个点：使用Promise.all([...]) 并发执行多个promise，但是最终结果数组按照的是传入数组的顺序，而不是按照完成时间排序，可以理解为他会记住传入任务的位置，最先完成的任务不是直接被放到第一个，而是被放到他对应的位置上

Promise.race则是只等待最快的那个，谁先完成就返回谁的结果（可以给操作设置定时器，放在一起race，如果定时器先完成就当做超时处理）

async/await

ES2017引入，使得异步代码和同步代码写起来一样

async关键字加在函数声明前面，表示函数是一个异步函数，异步函数的返回值自动包装为Promise

而await关键字只能在async函数里面使用，会暂停函数的执行，等待Promise完成后拿到结果，此时返回的结果也就是之前resolve发出的和.then接收的结果

但是await并没有阻塞整个程序，当等待的时候如果有其他代码，还是会在这个空出来的时间继续执行
